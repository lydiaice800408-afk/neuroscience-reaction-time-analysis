# Neuroscience Reaction Time Analysis

## Overview

This project analyses reaction time data from two cohorts of first-year Neuroscience students.

The dataset contains measurements collected in 2018–19 and 2025–26 using the same experimental procedure.

## Research Questions

- Does reaction time differ between the morning and afternoon?
- Does reaction time differ between the two student cohorts?
- Is reaction time associated with chronotype (owl/lark)?
- Are caffeine consumption and gaming associated with reaction time?

## Methods

Data analysis will be conducted using Python, including:

- Pandas
- NumPy
- Matplotlib
- SciPy
